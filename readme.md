# 🌏 Local Turístico - Busan

Este projeto foi desenvolvido com o objetivo de praticar a criação de páginas web utilizando **HTML e CSS**, com foco na construção de layouts modernos e na apresentação de conteúdo informativo sobre destinos turísticos.

A página apresenta a cidade de **Busan**, na Coreia do Sul, destacando pontos turísticos históricos e culturais, com uma estrutura visual organizada e agradável.

---

## 🚀 Conteúdos abordados

Durante o desenvolvimento deste projeto, foram trabalhados os seguintes conceitos:

- Estruturação de páginas com HTML5  
- Uso de tags semânticas  
- Estilização com CSS3  
- Organização de layout (cores, espaçamento e tipografia)  
- Uso de fontes externas (Google Fonts)  
- Aplicação de imagens e composição visual  

---

## 🛠️ Tecnologias utilizadas

- HTML5  
- CSS3  
- Google Fonts
